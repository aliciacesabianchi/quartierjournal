## Chreis+ feeds (aggregator data, not confirmed with the organisers)

Staged by the data pipeline from the Chreis+ ICS and GeoJSON feeds (CC BY-SA 4.0, attribution required; the feeds exclude images and original source prose, and so does this import). Last seen: 2026-11-18.

- **Places:** 489 imported as venues (marked *found via Chreis+*), 12 matched to venues that already existed (linked, not duplicated), 8 skipped as outside the city perimeter.
- **Sessions:** 1227 dated sessions grouped into **1165 activities** (same title, same listing page and same address). 838 have a date today or later and are published; 327 are in the past and are kept as history but not published.
- **Where:** 273 activities could be placed at a known venue by their address (this also gives their Kreis). For 376 more, the Kreis was derived from the postal code (rule: at least 3 known places carry that code and all are in one Kreis; 15 codes qualify; this is marked as derived on the site). The rest keep the feed's address text and the Kreis stays unknown. 198 have no location at all.
- **Times:** a start time of exactly 00:00 is treated as "no time given" (51 sessions). There are no end times, ages, prices or registration details in the feed, so they stay unknown.
- **Links:** the feed's event page is stored as a *listing* link, never as the organiser, because the original organiser is unverified. The feed itself is stored as the *discovery* link.
- **Shown as:** verification level *secondary source*, so the site labels them "found via Chreis+, not yet confirmed with the organiser". An admin can promote an entry to *provider verified* after checking it.

Possible duplicates between a feed entry and a verified activity (not merged):

- Feed entry **Babykonzert «Summ summ summ»** has the same title as the verified activity **Babykonzert – Summ summ summ**: possible duplicate (kept separate).


## How details were interpreted

- **Dates:** only rows with `session_date` became dated sessions. Weekday patterns are "usually" templates, never upcoming sessions.
- **Selected dates:** templates are marked `selected_dates` ("on some Wednesdays, check the organiser") when the notes say the offer runs on selected or certain dates only.
- **Ages:** numbers are filled only when the source gives units ("From 4 months", "2½–5 years", "0–4 years"), plus "All ages" and "Birth to kindergarten" (minimum 0, maximum unknown). Vague texts ("Preschool", "Up to 6" without a unit, "Approx. …", "exact ages unknown") stay unknown. The original text is always displayed.
- **Price:** `is_free` is only set to true when the text starts with Free or Gratis. "No purchase required" stays unknown. The original text is always displayed.
- **Registration:** mapped to required, recommended, not required or unknown. The original wording is kept and shown.
- **URLs:** `provider_url` becomes the organiser link. Aggregator hosts (chreis.plus, kikuka.ch, kulturzueri.ch, mamiio.com) are stored as *discovery* links, never as the organiser. `source_url` and `discovery_url` are kept with their own roles.
- **Organisers:** linked only where the organiser URL host matches a website in `discovery_directory`. No organiser names were invented.
- **Licence:** the Chreis+ feeds are CC BY-SA 4.0. Activities discovered via Chreis+ need attribution on display.
